## Repository Layout

The repo is structured as follows:
- PCB-related KiCad files in the `PCB/`
- KiCAD case design in `CAD/`
- Software related stuff is located in `Software/`
- For a rough BOM, see `BOM.csv`
- For my development log, see `JOURNAL.md`
- HackClub Readme is located in `README-original.md`
